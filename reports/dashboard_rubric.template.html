Benchmarks and counterevidence

The full matched 40-month sample gives memory MAE 4.199 → 4.198 after tone. With seasonality and survey-mode controls, 3.857 → 3.527. Carrying forward prior ICS gives 3.725. All content features together give 4.737.

The original nominal interval for the controls-model media increment excludes zero, but the new 14-comparison Holm-adjusted bootstrap p-value is 0.147. The advantage over persistence remains uncertain. Under the strictest coverage rule, only 13 months remain and the increment reverses to +0.299.

Accumulated prices shrink the descriptive residual from 28.25 to 7.08 points. Purchasing power, strong benchmarks and coverage sensitivity challenge a broad media-only account. All new checks are retrospective and exploratory.

Methods, provenance and offline reproduction

All 1,473 primary items were directly coded by GPT across sessions; immutable model versions were not retained. One human annotator independently labeled the 300-item reference according to the project owner’s source correction. There are 293 valid pairs and seven missing labels. The correction record and hashes are preserved in data/shareable/human_reference/protocol.json.

Expanding standardized ridge regression uses penalty 1 and origin-available targets. Seasonal controls and the April–July 2024 web-survey ramp are fixed. No respondent exposure or psychological mechanisms are identified.

Run python scripts/reproduce_submission.py to verify the frozen study and the additions. Run python scripts/run_rubric_extension.py --verify for the additions alone. Public replay uses supplied labels, curated event metadata and archived macro vintages. Private text extraction, human work logs and semantic judgments are not independently reproduced.

Update this monitor
  1. To rebuild the current frozen view, run python scripts/build_dashboard.py after reproduction. Reopen or reload the HTML file.
  2. For new observations, create a separate dated study version. Archive official release vintages and media timestamps, preserve the old inputs and record coverage, labels and provenance before the next sentiment outcome.
  3. Freeze the new cutoff, media period and model specification before evaluation. Recompute analyses, then rebuild and verify the dashboard and package.
