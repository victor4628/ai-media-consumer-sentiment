# Exploratory checks added after the first result read

The primary labels remain sealed. No coding changes followed analysis.

The first run showed higher descriptive fit after adding cumulative prices, and a media improvement in the model with seasonality and survey-mode controls. These observations motivated two additional checks before interpretation:

1. Compare cumulative prices with a linear time trend in the descriptive OLS accounting and full-history macro forecasting. This tests whether apparent price-level explanatory power is specific to prices rather than a generic persistent trend.
2. Carry the already specified seasonality/mode comparison through every coverage, duplicate, geography, penalty and period sensitivity. These are robustness follow-ups after seeing the initial gain, not independent confirmation.

The full-macro price-level reference is December 2008, available at every origin. December 2009 is not yet released at the first December 2009 forecast origin and therefore cannot serve as the denominator there. The core media-period price reference remains December 2018 as specified.

Training-mean forecasts are also retained as a transparent check of the pure-economic baseline. All specified results are reported. No winning model is promoted to a confirmatory result.
