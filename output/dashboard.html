RQ5 / RQ6 · Benchmarks and counterevidence

The full matched 40-month sample gives memory MAE 4.199 → 4.198 after tone. With seasonality and survey-mode controls, 3.857 → 3.527. Carrying forward prior ICS gives 3.725. All content features together give 4.737.

The method-controls media increment is −0.330 [−0.585, −0.072], but the advantage over persistence has an interval spanning zero. Under the strictest coverage rule, only 13 months remain and the media increment reverses to +0.299. Intervals are exploratory and not adjusted for multiple specifications.

Accumulated prices shrink the descriptive residual from 28.25 to 7.08 points. Purchasing power and coverage sensitivity challenge a strong media-only account.

Methods, coding audit and reproduction

Memory includes unemployment, PCE annual inflation, latest released annualized quarterly real GDP growth, and prior available ICS. Household adds real income growth and accumulated prices. Method controls instead add seasonality and the April–July 2024 web-survey ramp. Expanding standardized ridge regression uses fixed penalty 1 and origin-available targets.

GPT directly coded all 1,473 core items across multiple sessions; exact immutable model versions were not retained. Cached DeepSeek V4 calls review a 300-item sample (150 news / 150 X): 293 valid pairs, 65.2% tone agreement, kappa 0.539. No human gold standard. FinBERT and RoBERTa were not run. Content is selected from sparse historical keyword/time windows.

Bands use prior released absolute forecast errors, after 12 calibration observations. Empirical coverage need not equal the nominal 95%. Reproduce arithmetic with python scripts/reproduce_submission.py. No API calls or credentials are required. Private text extraction and semantic inference are not rerun.
